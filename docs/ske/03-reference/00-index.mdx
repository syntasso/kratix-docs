Use these references to look up fields, supported values and behaviour. Start with the
[Enterprise overview](/ske) for installation and task-based guides.
Core Kratix APIs are defined in the [Kratix reference](/category/reference).

## Platform APIs

- [SKE Operator](/ske/reference/ske-operator): `Kratix` and `SKEIntegration`, installation configuration and status.
- [HealthDefinition](/ske/reference/healthdefinition): health checks declared by a Promise.
- [HealthSource](/ske/reference/healthsource): importing health records from a bucket.
- [UpgradePlan](/ske/reference/promise-upgrades/upgrade-plans): desired Promise upgrades.
- [UpgradeRun](/ske/reference/promise-upgrades/upgrade-runs): upgrade execution and progress.

See [Promise upgrade concepts](/ske/reference/promise-upgrades/intro) for the relationship
between upgrade plans and runs.
