SKE integrations connect your platform to developer portals and infrastructure tools.
Choose the guide for the outcome you need:

- [Portal integrations](./portal-integrations/intro): publish Promises and request forms
  to Backstage, Cortex or Port. Backstage and Cortex use the shared Portal Controller;
  Port uses the separate Port Controller and is a Preview feature.
- [Terraform Enterprise and HCP Terraform](./tfe): use the Terraform State Finder
  pipeline image to connect Promise workflows to Terraform workspaces.
- [MCP Server (Preview)](./mcp): expose platform capabilities to MCP clients.
- [SKE Lift (Preview)](./skelift): turn existing cloud resources into governed Promises
  with agent skills and CLI plugins.

Check [supported versions and compatibility](/ske/releases/compatibility) before
installing or upgrading a component.
