Portal Patch is an optional helper image for declarative edits to generated entities,
forms and workflows. Its execution instructions and grammar are now together in
[Portal Patch recipes](./recipe-reference).

## How it runs

See the [complete configure-lane example](./recipe-reference#how-it-runs), including
the Promise binding and verification. Portal Patch is not required to install the controller.

## Recipes are container arguments

Each argument is a recipe. Recipes for a file apply in order, not independently.
See [argument ordering](./recipe-reference#recipes-are-container-arguments).

## The image tag is the grammar version

Pin a released helper version independently of the Portal Controller.
See [version requirements](./recipe-reference#the-image-tag-is-the-grammar-version).

## Failure behaviour

Recipe errors stop publication. See [failure behaviour](./recipe-reference#failure-behaviour)
for missing-file handling and the boundaries of the all-or-nothing recipe guarantee.

## Choosing between a recipe and your own container

Use recipes for known document fields and a script for computed values, external calls or
new files. See [choosing an approach](./recipe-reference#choosing-between-a-recipe-and-your-own-container)
and the [PortalCustomization reference](../customization).
