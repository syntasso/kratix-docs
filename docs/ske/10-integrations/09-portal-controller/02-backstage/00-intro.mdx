Publish your Promises in Backstage so developers can discover, request and manage resources.

The integration has two directions:

```text
Promise API → Portal Controller → Git or bucket → Backstage catalogue and Templates
Developer request → SKE backend plugin → Kubernetes API or GitOps → Kratix
```

The Portal Controller generates catalogue files. Backstage reads them; it does not receive
them through its API. The two SKE plugin packages provide request actions and resource pages.

## Set up the integration

1. [Generate Backstage entities](./generate-entities). Install or reuse the controller,
   choose catalogue storage, label a Promise and verify its files.
2. [Configure Backstage](./configure-backstage). Install the plugins and configure discovery.
   Verify the Promise Component and its Template.
3. [Send resource requests to Kratix](./send-resource-requests).
   Configure transport, approval and namespaces. Create, update and delete a resource.

Catalogue storage and request storage are separate choices. Git-based requests need a GitOps
agent to apply them to the platform.
