## Overview

SKE Lift turns an existing cloud estate into Kratix Promises and Resource
Requests. It ships as two plugins to the [Kratix CLI](/main/kratix-cli/intro),
`kratix-skelift-check` and `kratix-skelift-review`, together with a set of agent
skills. See [SKE Lift](/ske/integrations/skelift) for how to install and use it.

`kratix plugin add skelift` installs the current release of both plugins. To
download a specific release, set your
[Syntasso Enterprise Release Token](/ske/reference/tokens#enterprise-releases-token)
as the value of the `GH_TOKEN` environment variable and use the `gh` cli:

```
gh release download $PLUGIN-$VERSION \
  --repo syntasso/enterprise-releases \
  --pattern '${PLUGIN}_$ARCH' \
  --output ${PLUGIN}_$ARCH
```

`$PLUGIN` is `kratix-skelift-check` or `kratix-skelift-review`. The available
architectures are `darwin_amd64`, `darwin_arm64` and `linux_amd64`.
