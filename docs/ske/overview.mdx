# Introduction

Syntasso Kratix Enterprise (SKE) is the supported enterprise distribution of Kratix.
It adds platform lifecycle management, Promise testing and upgrades, resource health checks,
a GUI and integrations. The [core Kratix documentation](/) covers Promises,
workflows, Destinations and StateStores shared with open-source Kratix.

## Install SKE

Start with [requirements and access tokens](/ske/installing-ske/intro), then
[install SKE with the Operator](/ske/installing-ske/install-with-operator).
There are separate guides for [air-gapped environments](/ske/installing-ske/air-gapped)
and [migration from open-source Kratix](/ske/installing-ske/migrating-from-kratix).

## Operate your platform

Understand the [platform architecture](/ske/reference/parts-of-a-platform) and
[prepare SKE for production](/ske/operations/production-readiness).
Use the guides for [upgrades](/ske/installing-ske/upgrades),
[backup and restore](/ske/installing-ske/backup-and-restore),
[health checks](/ske/guides/healthchecks) and the [GUI](/ske/guides/ske-gui).
For diagnostic checks, see [Troubleshoot SKE](/ske/operations/troubleshooting).

## Integrate developer interfaces and tools

Choose a developer portal in [Portal integrations](/ske/integrations/portal-integrations/intro).
Backstage and Cortex use the shared Portal Controller; Port uses its own controller.
For infrastructure tooling, see [Terraform Enterprise and HCP Terraform](/ske/integrations/tfe).

:::info Preview features
[Port](/ske/integrations/port), [MCP Server](/ske/integrations/mcp) and
[SKE Lift](/ske/integrations/skelift) are Preview features. Review the
[Preview support policy](/ske/support#preview-features) before adopting them.
:::
