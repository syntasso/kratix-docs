This section covers everything you need to get SKE installed and running: 
choosing an installation method, adding supporting components like the GUI and Health Agent, 
and keeping your platform upgraded once it's live.

<PartialPointToKratix />


## Choosing an installation method

Not sure which one applies to you?

- For development, testing, or the fastest way to get started, use [Preconfigured installation](./preconfigured-install).
- For production, or if you need to customise the installation, use [Advanced installation](./advanced-install). 
  - If your cluster is also air-gapped, complete [Air-gapped installation](./air-gapped) first for the extra registry and manifest configuration you'll need.

## Additional components

Once SKE is installed, you may also want:

- [SKE Health Agent](./ske-health-agent) — install the Health Agent in your Destinations.
- [SKE GUI](./ske-gui) — deploy the GUI to view your Kratix Promises and Resources.

## Upgrading and removing SKE

See [Upgrades](./upgrades) for how to move your SKE installation forward safely, using the same declarative mechanism as installation itself.
