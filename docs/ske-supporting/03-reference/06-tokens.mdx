SKE uses separate credentials for private container images and private GitHub release assets.
See [Prerequisites](/ske/installing-ske/intro) to obtain and use your tokens.

## Syntasso registry token

Use this credential to pull images from `ghcr.io/syntasso` as `syntasso-pkg`.
See [registry token usage](/ske/installing-ske/intro#syntasso-registry-token) for the
Helm licence value and Kubernetes image pull Secrets.

## Enterprise releases token

Use this credential as `GH_TOKEN` when downloading private assets from
`syntasso/enterprise-releases`. See [Enterprise releases token usage](/ske/installing-ske/intro#enterprise-releases-token).
